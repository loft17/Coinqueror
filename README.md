# Coinqueror
Coinqueror es un juego incremental en HTML, CSS y JavaScript donde lanzas una moneda al aire para ganar dinero, desbloquear logros y mejorar tus estadísticas. Cuanto mayor sea tu racha de caras, mayor será la recompensa. Pero cuidado… la moneda no siempre está de tu lado.

🎮 Características

🎲 Lanzamiento animado en 3D con física visual realista

💰 Sistema incremental con mejoras progresivas

🏆 21 logros desbloqueables con recompensas económicas

📈 Multiplicador por racha de caras consecutivas

🛒 Tienda de mejoras

🍀 Aumentar probabilidad de cara

⚡ Reducir tiempo de vuelo

💰 Incrementar valor base de recompensa

🔊 Efectos de sonido dinámicos generados con Web Audio API

💾 Sistema de guardado automático con localStorage

📤 Exportación e importación manual de partidas

🔥 Opción de Reforma Total (reset completo)

🧠 Mecánica del Juego

Cada lanzamiento tiene una probabilidad base de 1% de salir cara.

Las mejoras permiten:

Aumentar la probabilidad hasta el 100%.

Reducir el tiempo de animación hasta un mínimo de 0.3 segundos.

Incrementar el valor base de cada recompensa.

Las rachas consecutivas aumentan el multiplicador de ganancia.

Los logros desbloqueados otorgan dinero adicional.

Exportar tu partida a un código encriptado Base64

Importar una partida desde un código válido

Reiniciar completamente el progreso
